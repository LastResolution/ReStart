# Support

[日本語](SUPPORT.ja.md)

Start with the [README](README.md), [JavaScript tile guide](docs/javascript-tiles.md), [updates](docs/updates.md) and [migration/rollback](docs/migration.md). Local Release build and portable packaging commands are in the README.

Use [Issues](https://github.com/LastResolution/ReStart/issues/new/choose) for ordinary bugs and feature requests. English or Japanese is welcome. Include ReStart version/build from Settings → About, Windows build, monitor/DPI configuration, steps and expected/actual behavior. For live tiles, include a minimal package with personal paths removed.

Report vulnerabilities privately using the route in [SECURITY.md](SECURITY.md). Do not post credentials, private layouts, app catalogs or unredacted logs/screenshots. Windows startup/Explorer integration can be disabled in Settings before removing or moving the installation.

ReStart is independent of Microsoft. The [validation record](docs/validation.md) describes tested environments; report platform-specific differences with their exact configuration.
