# Support

Start with the [README](README.md), [JavaScript tile guide](docs/javascript-tiles.md), [updates](docs/updates.md) and [migration/rollback](docs/migration.md). Local Release build and portable packaging commands are in the README.

Use [Issues](https://github.com/LastResolution/ReStart/issues/new/choose) for ordinary bugs and feature requests. English helps everyone follow the discussion; reports in other languages are also welcome. Include ReStart version/build from Settings → About, Windows build, monitor/DPI configuration, steps and expected/actual behavior. For live tiles, include a minimal package with personal paths removed.

Settings → About → **Diagnostic information** shows a whitelist-only report you can review and copy. It contains versions, presentation mode and classified error codes, without private paths, app inventories, tile inputs, credentials or raw logs. Nothing is uploaded automatically. Paste it into a report only after reviewing it; add reproduction steps separately.

Report vulnerabilities privately using the route in [SECURITY.md](SECURITY.md). Do not post credentials, private layouts, app catalogs or unredacted logs/screenshots. Windows startup/Explorer integration can be disabled in Settings before removing or moving the installation.

ReStart is independent of Microsoft. See [compatibility](docs/fidelity.md) for platform coverage; report platform-specific differences with their exact configuration.
