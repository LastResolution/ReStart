## 要望に合わせた拡張

本家の内部仕様と同じとは主張しない機能です。

- グループ外へ出した単独タイルは見出しや余分な幅を持ちません。
- グループ幅は内容で決まり、6 / 8セルの最低幅を持ちません。設定した列数はタイルの折り返し上限です。
- 半セル単位の横位置と横スクロールを追加。端へ来た場合だけ作業領域を広げ、収まる内容には不要な縦スクロールを出しません。Shift＋ホイールで横移動します。
- タイルの表示名・個別背景色は ReStart メニューに置きます。テーマ色へ戻せます。個別色は保存し JS 色より優先、高コントラストはさらに優先します。

余計な縦余白、常時拡張、固定幅と横アンカー、フォルダーの上線 / 最小行を今回の確認で修正しました。一次資料へのリンクは英語版と[調査](research.md)にあります。

描画方式・アニメーション・検索索引・履歴・Jump Lists・旧 UWP 通知などは差分が残ります。物理ドラッグは補助ツールの識別エラーで再確認できておらず、本家実機や ARM64 の成功も主張しません。[再現仕様](fidelity.md)と[検証](testing.md)に範囲を残します。
