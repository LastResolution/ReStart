# 更新確認

[English](../updates.md)

「設定 → 更新」で公開 GitHub Releases を確認します。API キー・アカウント・トークンは不要です。通常は安定版のみ、必要ならプレリリースも対象にできます。起動時の確認は任意で、入力やカタログ読み込みを妨げません。

バージョンは数値とプレリリースの優先順位で比較します。下書き、対象アーキテクチャの ZIP / SHA-256 が欠けたリリースは除外します。100件×最大5ページを読み、未完了・不正な応答を「最新版」とは表示しません。回数制限・サービス障害・接続失敗は区別します。

固定の api.github.com エンドポイントへアプリバージョンを付けて問い合わせます。Authorization は送らず、リダイレクトも無効です。アプリ一覧・レイアウト・写真フォルダ・利用履歴は送信しません。プレビューでは通信しません。

更新はリリースページを開くまでです。ZIP とチェックサムを取得し、トレイから終了、全体を展開して再起動してください。旧開発版の資格情報は値を読み出さずに ReStart 自身の旧ターゲットだけ削除します。現在のアプリはトークンを保存・利用しません。
