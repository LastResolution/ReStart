# 更新チェック

[English](../updates.md)

設定 → 更新で手動チェック、起動時チェック、プレリリースを含める設定を変更します。現在の 0.x はプレリリースなので、通知を受けるにはプレリリースを有効にします。

バージョンは数値と SemVer の優先順位で比較し、ビルド情報は比較対象から外します。下書きと、実行環境に対応する ZIP / SHA-256 の両方がないリリースは除外します。最大100件×5ページを読み、不完全な応答を「最新」と判定しません。

## 非公開版の認証

対象リポジトリ LastResolution/ReStart だけに **Contents: read** を与える fine-grained GitHub トークンを作成し、設定内の GitHub アクセスから保存します。リポジトリ権限を持つアカウントと適切な期限を使います。資格情報の保存・削除は、設定画面の保存ボタンとは独立して即時反映します。

Windows 資格情報マネージャーの現ユーザー用 `ReStart/GitHub/LastResolution/ReStart` に保存します。レイアウト JSON・エクスポート・配布物には含めず、入力欄にも再表示しません。設定から削除できます。

非公開リポジトリは権限がない場合404を返すことがあります。認証不足・期限切れ、回数制限、接続 / サービス障害、不正応答は「最新」と区別して表示します。

## 通信とインストール

通信先は固定の api.github.com リリース API です。アプリ版と設定済みの認証を送り、アプリ一覧・配置・使用履歴は送りません。認証は要求単位で付け、自動リダイレクトを無効にしています。起動時確認は非同期で、入力やアプリ列挙を待たせません。

更新確認だけを行い、固定リポジトリのリリースページを開きます。自動ダウンロードやインストールはしません。終了後に ZIP 全体を展開し直してください。SHA-256 は手動確認できます。

プレビューでは通信と本番資格情報の変更を無効にします。自動テストは架空 HTTP 応答と専用の一時資格情報を使います。実際の認証付き確認にはユーザーが設定したトークンが必要です。
