# 設定移行と復元

[English](../migration.md)

通常設定は %LOCALAPPDATA%\ReStart\layout.json、プレビューは別領域です。v1.0 のスキーマは4です。旧スキーマ1～3の設定・ID・名前・起動先・所属を保って移行します。

旧版の無名1タイルグループは独立したピンになります。スキーマ4は独立タイルとグループ内タイルの見える基準線を揃えます。スキーマ3の独立行は旧見出し補正分を半セルへ丸めて差し引き、名前付きグループは変えません。1/2は元の子位置から移行します。移行は一度だけです。X 座標・個別色を保存し、インポートではこの PC の設定を保持します。

更新前の元バイト列を layout.json.schema<version>-<id>.bak、同一スキーマのアプリ更新なら layout.json.upgrade-<id>.bak に保存します。回転式 layout.json.bak とは別に残し、バックアップできない場合は置き換えません。

「レイアウトとデータ」に移行前後のバージョン・スキーマ・日時・バックアップパスを表示します。未来のスキーマと新しいアプリが保存したファイルを旧版で上書きしません。番号を手で変えて互換性を強制しないでください。

復元時は終了し、現在の設定と tiles を別途コピーし、目的の旧版に合ったバックアップを layout.json へ戻して起動します。実行場所が変わればスタートアップ・Explorer 登録を見直してください。レイアウト出力に JS ソースと写真フォルダ指定は含まれないため、tiles も別途保管します。破損ファイルは .corrupt-<timestamp> へ保存し、有効な回転バックアップを復旧候補とします。
