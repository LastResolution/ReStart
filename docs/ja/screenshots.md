# ドキュメント画像

[English](../screenshots.md)

README画像はアプリ名・タイル名・ライブタイル内の見出し・曜日・日付・設定・サンプル文書名まで**全体を英語**にします。一般的なアプリだけを選んだデモ配置、架空の文書、合成メトリクス、生成した写真色を使い、個人のデスクトップや全アプリ一覧を撮影・公開しません。

```powershell
./scripts/render-readme.ps1 -Executable src/ReStart.App/bin/Release/net10.0-windows/ReStart.exe
```

Releaseビルド後に実行します。専用 `--render-docs` は通常の多重起動管理・トレイ・フック・ピン留めIPC・起動登録より前に分岐し、ウィンドウを一切表示せずWPFを直接描画します。毎回無視対象の専用データを使い、実設定・壁紙・写真指定・データ接続・文書履歴は使用しません。

固定した一般的なアプリの実アイコンだけをShellから取得し、言語に依存しないパッケージ/実行ファイルの識別子で照合します。必要な実アイコンが見つからなければ失敗させます。代替の地球儀やリストアイコンに別アプリ名だけを付けて公開しません。撮影用PCに対象アプリを用意するか、構成を明示的に編集します。

画像は `artifacts/readme-render/<run>/` に生成します。明暗の全画面、グループ、展開フォルダ、選んだアプリ一覧、オフライン検索を含み、時刻も英語サンプルの固定値です。FFmpegがあればネイティブの開閉フレームからGIFを生成します。実デスクトップは記録しません。

設定・起動オプション画像は `scripts/test-fidelity.ps1` の英語fixture出力を使います。8言語×明暗を検査しますが、対話型のネイティブ試験は専用デスクトップまたはCIで実施します。作業中の利用者の画面は撮影しません。起動例の `%USERPROFILE%\Documents` は展開しない文字列です。

コミット前にPNG全件とGIFの代表フレームを目視し、タイル内部まで英語であること、実アイコンの見やすさ、ユーザー名・パス・個人文書・実際の地域・通知・タスクバー・デスクトップの不在、画像メタデータを確認します。レビューしたPNG/GIFだけを `docs/images` へコピーし、fixtureデータ、キャッシュ、JSON、ログ、接続、全アイコン一覧は含めません。

`scripts/check-readmes.ps1`、ステージ済みprivacy検査、`git diff --check`を実行します。privacy検査は文字列やキー形式を探すもので、画像内の全単語を読む機能や目視確認の代わりにはなりません。8言語のREADMEで同じ英語画像を使い、翻訳本文はAI翻訳と明記します。
