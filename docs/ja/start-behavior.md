# スタートの動作

[English](../start-behavior.md)

アプリのタイルを右クリックし、**ReStart → 起動オプション…**から、追加引数・作業フォルダー・管理者実行を指定できます。**起動オプションを指定する**を無効にすると入力値を残して標準の起動に戻ります。空白のあるパスは引用符で囲んでください。既存ショートカットの引数はWindows側で引き継ぎます。対応するデスクトップアプリやショートカットが対象で、管理者実行はWindowsが対応する場合だけ選択できます。UACの確認はWindowsが行います。無効な作業フォルダーは保存前に検出します。

**ReStartの設定 → スタートの動作**で機能を個別に切り替え、保存すると反映されます。Windowsキー・スタートボタンの置き換え、自動起動、非アクティブ時に閉じる設定、壁紙、色、アニメーションは既存の各設定から変更できます。

| 設定 | 既定値 | 無効時の動作 |
| --- | --- | --- |
| ホバーでサイドバーを展開 | 有効 | メニューボタンでの明示的な展開は利用可能 |
| サイドバーのフォルダー | ドキュメント、ピクチャ | 各項目を個別選択可能。すべて非表示にも対応 |
| Windowsの設定を検索 | 有効 | 設定の結果を除外。アプリ検索は利用可能 |
| インデックス済みファイルを検索 | 有効 | 待機中の検索を取り消し、ファイル結果を除外 |
| 最近・よく使う文書を表示 | 有効 | Windowsの文書履歴への問い合わせを停止 |
| ホバーでタイルを明るくする | 有効 | キーボードのフォーカス表示と押下反応は維持 |
| ホバーでグループの範囲を表示 | 有効 | 編集・ドラッグ中の範囲表示は維持 |
| 単独タイルを重ねてグループを作成 | 有効 | 重なりによる自動グループ化を停止 |
| グループ内で重ねてフォルダーを作成 | 有効 | 既存フォルダーとメニューからの明示的な作成は利用可能 |
| ドラッグ中に端で自動スクロール | 有効 | ドラッグによるスクロールと空白領域の拡張を停止 |
| ドロップのヒントと待ち時間の進捗 | 有効 | 位置のプレビューは維持し、説明と進捗を非表示 |
| 最近追加したアプリ | 有効 | アプリ一覧の該当セクションを非表示 |
| よく使うアプリ | 無効 | ReStartからの起動回数の記録を停止し、該当セクションを非表示 |

外観の**アニメーション**は開閉・タイルの押下・フォルダー展開に適用します。Windowsのアニメーション無効設定とハイコントラストを優先します。

アプリ検索は即時表示します。Windows設定15項目は翻訳名と英語名で検索でき、ファイル名検索は入力後200ms待ってローカルのWindowsインデックスへ問い合わせます。最大20件とし、ディスクの再帰走査は行いません。インデックスが無効・利用不能でもアプリと設定の検索は使えます。

`layout.json`と同じ場所の`activity.json`に、アプリの識別子、初回検出日時、任意の起動回数を保存します。初回起動時の既存アプリは「最近追加」に含めません。新規検出アプリは7日間、よく使うアプリは最大6件を表示します。起動回数は機能を有効にした間のReStartからの起動のみが対象です。

**アプリ履歴を消去**で日時と回数を消去します。既存アプリが新規扱いにならないよう検出済み一覧は維持します。履歴は配置のエクスポートに含めず、外部へ送信しません。よく使うアプリを無効にしても既存の回数は残り、再開または明示的な消去を選べます。

文書履歴はWindowsの設定を尊重して取得し、ReStartの履歴ファイルへ複製しません。独自タスクや独自・ピン留めカテゴリは公開APIの対象外です。[互換性](fidelity.md)も参照してください。
