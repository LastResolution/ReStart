# リリースと GitHub 運用

[English](../releasing.md)

短い機能 / 修正ブランチと変更単位のコミットで作業し、PR のビルド / テストと x64 / ARM64 のクリーン配布ジョブがすべて成功してから Squash merge します。マージ後にブランチを削除します。一次文書・リリースノートは英語とし、日文を併記します。

## main の保護

2026-10-18 に非公開 main の保護を再設定しましたが、GitHub は Pro または公開化を必要とする HTTP 403 を返しました。**サーバー上の保護は有効になっていません。** PR 運用を守ることと、強制的な保護は別です。リポジトリは非公開を維持します。

対応プランへ変更後は `./scripts/protect-main.ps1` で .github/main-protection.json を適用し、返却値を検証できます。PR、会話解決、直線履歴、3チェック成功を必須にし、管理者にも適用、force push / 削除は禁止します。単独保守なので承認レビュー数は0です。プランエラーを成功と扱いません。ユーザー指示なしに公開化・購入は行いません。

## バージョンと配布

Directory.Build.props と日英ノート・変更履歴・検証記録を PR で更新します。配布 README の版はパッケージ生成時に埋めます。

~~~powershell
git switch main
git pull --ff-only
git tag -a v0.5.0 -m "ReStart v0.5.0"
git push origin v0.5.0
gh run list --workflow release.yml
~~~

タグ・プロジェクト・日英ノートの版、main 由来を確認し、ビルド / テスト後に別ジョブで両アーキテクチャを生成します。両方成功後、非公開プレリリースを作ります。

新規ステージに本体・ワーカー・サンプル・6ライセンス文書・LICENSE・日英 README の15ファイルだけを収めます。個人配置・一覧・ログ・資格情報は含めません。実際に公開された ZIP を取得し、SHA-256、PE、版、内容を確認し、x64 の描画・主要検証・多重起動・JS サンプルを確認します。ARM64 実行は実機待ちです。

配布物は未署名です。公開済みタグを書き換えません。コード変更が必要な修正は新しいタグにします。v0.2.0 はクリーン復元不足で失敗し、タグを残して v0.2.1 で修正しています。

通常 CI は contents:read、公開ジョブだけ contents:write と actions:read です。Actions は SHA 固定です。更新時は終了して ZIP 全体を展開し、パス変更時は自動起動を保存し直します。[設定移行](migration.md)の原本で旧版へ復元できます。
