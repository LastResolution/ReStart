# 表示言語とテーマ

[English](../localization.md)

設定 → 言語で日本語・English・システムを選択します。保存で本体と日付書式を切り替え、設定は開き直して反映します。日本語以外の OS では英語を使います。OSのアプリ名、保存した名前、JS の出力は書き換えません。

翻訳は ReStart.Core/Locales の日英 JSON、参照は安定した TextKey です。C# は TextCatalog.T / F、XAML は Loc を使います。キー追加時は enum と両言語を同時更新し、キー集合・空値・書式を検証します。日本語の UI 文言を C# / XAML へ直接書きません。将来形式の判定は例外型で行い、訳文を比較しません。

一次ドキュメント・開発コメントは英語、日文は root の .ja.md または docs/ja へ置きます。

設定の保存ボタンは固定し、チェック・選択・スライダー・スクロールバー・カレンダーは共通テーマを使います。Start のシステムモードは Windows のシステムテーマを参照します。高コントラストを最優先し、効果や色を抑えます。

クラシックなアプリタイルは共通アクセント（明示した個別色で上書き可能）、後期タイルは均一な半透明背景、一覧アイコンは透明背景です。Start 全体へのアクセントはダーク時だけに適用し、グループ別色にはしません。

プレビューの設定は独立画面として表示し、自動起動・更新通信・本番資格情報の変更は無効です。通常は本体をオーナーにするダイアログです。
