# 言語とテーマ

[English](../localization.md)

対応言語は en・ja・de・fr・es・ko・zh-Hans・zh-Hant とシステム言語です。地域タグから対応言語を選び、zh-TW/HK/MO/Hant は繁体字、それ以外の中国語は簡体字、未対応言語は英語へフォールバックします。保存後にメイン画面と書式が切り替わります。設定画面は開き直してください。OS の名前と、自分で変更したタイル・グループ名は保持します。ライブタイルの既定名は言語切替に追従し、実行中のスクリプトも新しい言語で再描画します。

TextKey の意味単位キーと8つの Locales/*.json を使います。全言語のキー・空文字・書式引数・地域判定をテストし、C#/XAML に日本語 UI をハードコードしません。コメント・API 文書は英語です。翻訳の自動検証はありますが、専門家による言語レビューは未実施です。

設定のナビゲーションは折り返し、内容はスクロールし、操作フッターを固定します。チェックボックス・コンボボックス・スライダー・スクロールバー・ダイアログ・カレンダーは共通テーマに従います。ハイコントラストを優先し、タイル個別色はテーマへリセットできます。グループ単位の色は設けません。壁紙はデスクトップ変更・再表示で更新し、同じパスの上書きやモニター別画像を扱います。

プレビューは実設定・起動登録・シェル登録・更新通信を変更しません。8言語×2テーマの描画を検証します。
