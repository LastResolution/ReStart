# 再現仕様と差分

[English](../fidelity.md)

基準は後期 Windows 10 の全画面スタートです。ReStart は独立実装で、機能があることと本家で同じ操作が確認できたことを区別します。Windows 10 の比較 PC / VM はありません。

| 項目 | 実装と限界 |
| --- | --- |
| 全画面・左バー | ポインターのある画面の WorkingArea。開き直すと検索・一覧・展開を閉じてタイル先頭へ戻る |
| 背景・テーマ | 壁紙ぼかしは Acrylic の近似。共通配色、8言語、ダーク / ライト / システム、高コントラスト |
| 色 | 全タイル共通のクラシックアクセント、半透明の後期タイル、ダーク時のスタート全体へのアクセント。グループ別色の根拠はない。タイル個別色は要望による拡張として追加 |
| グループ | 独立した列・半セルの縦位置、直接命名、衝突先プレビュー。末尾余白を判定から除外。内容幅と半セルの横位置・横スクロールは拡張。6 / 8セルは折り返し上限。本家のスナップやアニメーションは未照合 |
| 単独タイル | 要望に合わせた ReStart の拡張。空き領域に出すと見出し・グループメニュー・余分な幅を持たない。旧形式の名前なし1個グループも移行。本家の内部仕様と同じとは主張しない |
| 移動 | セル・所有権・保存、衝突 / 取消で内部位置を保つことを自動検証。物理ドラッグの再確認は補助ツールのエラーで未実施 |
| フォルダー | 約1秒の重ね合わせ、行内展開と直接命名。展開は一時的な押し出しで、親や内容の保存座標は保持 |
| 全アプリ | OS名・アイコン・階層、行内開閉、文字ジャンプ、幅の均等化。曖昧な候補は重複し得る。日本語の五十音分類は未対応 |
| 検索 | 初回入力を保持し列挙後に再検索。英数幅・かなを正規化。ファイル / 設定索引・Web・Cortana は対象外 |
| 個別メニュー | ピン留め / 解除、対応する Shell verb のその他 / アンインストール。読み取り確認済み、管理者実行や削除は実行未検証。Jump Lists は未実装 |
| Windows キー・タスクバー | 単押し・組み合わせの状態ロジックを検証。物理通し操作は未検証。Start ボタンは Explorer の UI Automation 境界で識別し、主・副タスクバーを対象にする |
| ライブタイル | 時計・日付・自作 JS。旧 UWP 通知や背景配信は非対応 |
| 保存・更新 | schema 4、移行原本保全、将来版の保護、版・ライセンス・移行表示、公開 API の認証なし更新確認。自動インストールはしない |
| 多重起動・自動起動 | 2パス10回起動で1個を維持。登録ロジックは専用キーで検証。実サインイン・ポリシーは未検証 |
| その他 | 最近追加 / 使用履歴、Windows の配置直接移行は未実装。Narrator・タッチ・IME全経路、電源操作も未検証 |

検証機は Windows 11 x64 build 26200 です。ARM64 はクロスビルドのみで、Windows 10 22H2、混在 DPI・複数画面は未検証です。

物理ドラッグはウィンドウの再選択後も `foreground window did not report a process id` となり、入力を停止しました。WPF のイベント・描画検証で代替成功とは扱いません。[検証](testing.md)・[記録](validation.md)・[調査](research.md)を参照してください。

## v1.0 の現行契約

スキーマ4へ旧1～3から原本を保存して移行します。8言語、12種類のJSタイル、4ワーカー共有、PC時刻・集計メトリクス・選択フォルダ写真・タイル内クリックに対応します。新規カスタムタイルは既存グループに割り込まず空き場所へ独立配置します。下端グループの移動中も盤面範囲を保ち、同一プレビューの再レイアウトを省きます。更新確認は公開APIを認証なしで利用し、資格情報UIはありません。最新の詳細はリンク先の英語版と[JSガイド](javascript-tiles.md)を参照してください。
