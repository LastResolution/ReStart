# ReStart v0.5.0

[English](https://github.com/LastResolution/ReStart/blob/v0.5.0/docs/release-notes.md)

配置・初回検索・外観を改善し、版・ライセンス・設定移行・更新確認を加えた非公開の開発プレリリースです。

## 配置とフォルダー

グループから空き領域へ出したタイルは、見出しや余分なグループ幅を持たない単独タイルになります。グループ幅は内容に合わせ、横位置は半セル単位で動かせます。横スクロールと Shift＋ホイール、左右の端スクロールに対応しました。移動開始だけで縦方向の領域を広げず、余計な縦余白も除去しています。

衝突相手の移動先を含むプレビューと確定が同じ計算を使い、内部タイルの位置を保持します。小タイル1個の高さや、末尾の見えない衝突領域も修正しました。

D&D のフォルダー作成はタイル中央で約1秒保持してから離します。開いた親は矢印になり、行の下に名前と内容を展開します。当時の公式映像を再確認し、余分な上線と小さい内容の最小行を修正しました。

単独タイル・内容幅・横方向の自由度は要望に合わせた ReStart の拡張です。

## 色・名前・検索・メニュー

タイルを右クリック → ReStart → 名前を変更 / タイルの背景色から個別に編集できます。色はパレット / #RRGGBB を指定し、テーマ色にも戻せます。全体のクラシックアクセント、後期の半透明タイル、ダーク時のスタート背景色も設定できます。

列挙前の E 入力を保持し、読み込み完了で Edge 候補を更新します。フォルダー内も含むアプリ単位のピン留め / 解除に対応し、Windows が有効な操作として提供する「その他」等を表示します。

## 情報・移行・更新

設定 → 情報に実行中の版・ビルド・アーキテクチャとライセンス全文、レイアウトとデータに直近の移行記録と復元用ファイルを表示します。

**保存形式は schema 3 です。** schema 1/2 の原本を保全してから移行します。旧形式の名前なし・タイル1個のグループは単独タイルになります。同じ schema 内でアプリ版が変わる場合も原本を残します。旧版に戻すには[移行手順](https://github.com/LastResolution/ReStart/blob/v0.5.0/docs/ja/migration.md)に従ってください。

更新は手動 / 起動時に確認できます。非公開リリースのトークンは Windows 資格情報に保存し、認証・回数制限・接続エラーを「最新」と区別します。配置やアプリ一覧は送りません。ダウンロード / インストールは手動です。

一次文書は英語に統一し、日本語版と日英の配布 README を付けています。

## 更新と検証範囲

旧版を終了し、対応アーキテクチャの ZIP 全体を展開して起動します。設定はローカルデータに残ります。場所が変わった場合は有効な自動起動設定を保存し直してください。ZIP は SHA-256 付き、未署名です。

Release ビルドは警告・エラー0、Core 151件。配置17・直接命名4・フォルダー10の WPF チェック、初回入力、一覧、メニュー、日英テーマ、移行、ライセンス、個別色を検証しています。

物理ドラッグは補助ツールの識別エラーで未再確認です。物理 Win / タスクバー、IME / Narrator 全経路、混在 DPI、ARM64 実機、Windows 10 22H2 との並行比較は未検証です。旧 UWP 通知、検索索引全体、使用履歴、Jump Lists は未実装です。[全体確認](https://github.com/LastResolution/ReStart/blob/v0.5.0/docs/ja/behavior-audit.md)を参照してください。
