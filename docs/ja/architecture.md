# アーキテクチャ

初回表示は進捗画面でアプリ一覧・アイコン・ライブタイルの初期フレームを準備してから行います。待機中もネイティブの入力欄で検索語を入力でき、表示時に引き継ぎます。Esc・再度の開閉操作・別アプリへの切り替えで取り消すと、後から勝手に開きません。サインイン時のバックグラウンド初期化では待機画面やタイルの通信を開始しません。

アイコンは最大4本のSTAスレッドで取得し、ユーザーのローカルデータにハッシュ名のPNGとして最大1,024件保存します。1日で更新し、元ファイルのサイズ・更新日時の変化でも失効します。破損時はShellから再取得でき、キャッシュの削除で設定は失われません。検索はネイティブの選択状態とEnterの起動先を揃え、入力欄のキャレットを維持します。

[English](../architecture.md)

ReStart.Core はモデル・配置・検索・翻訳・保存・更新 API の検証を扱います。ReStart.App は WPF、シェル、入力フック、トレイ、設定とワーカー管理、ReStart.TileHost は Jint による JS の実行を担当します。

## 配置

TileLayout は明示したセルを先に予約し、未配置 / 衝突項目を配置します。4サイズは1×1 / 2×2 / 4×2 / 4×4です。GroupLayout は列と半セル単位の縦アンカーを保持し、プレビューはモデルを変更せず、確定時と同じ衝突計算を使います。グループ移動では内部タイルの ID・サイズ・セルを変えません。

schema 4 の IsStandalone は単独タイルを表します。見出し・グループメニューを持たず、実際のタイル幅と高さで判定します。タイルの Column が列内のオフセット、グループの Row が画面上の縦位置です。これはユーザー要望に合わせた ReStart の拡張で、本家の内部モデルと一致するという主張ではありません。グループの幅は内容から求め、設定の6 / 8セルは内部の折り返し上限です。X は横方向の論理セルで、半セル単位に移動し、画面外の内容は横スクロールします。

GroupBoardPanel は同じ矩形で計測・描画し、LayoutEditor が所有権を一度だけ移します。フォルダー展開は一時的な高さで、保存したルート座標を変更しません。単独フォルダーの展開も親の横位置を保持します。

LayoutHistory はグループと1階層の子タイルだけを深くコピーし、100操作・32 MiB の範囲でメモリに保持します。保存成功時に1操作を記録し、同一内容の保存はやり直しを消しません。取り消し後の新規編集はやり直しを破棄します。テーマや自動起動、移行情報、JS実行状態、外部ファイルは履歴の対象外です。Undo / Redo の保存失敗では履歴位置も戻します。画面を閉じても保持し、アプリ終了で破棄します。

編集モードはタイル起動を抑え、IDで選択を保持します。親フォルダーとその子は同時選択しません。TileBatchMove.Plan はコピー上で位置を固定・検証し、選択したセルをまとめて予約して衝突だけを再配置します。プレビューと確定は同じ計算結果を使い、取消・無効な移動では原本を変更しません。同じ移動先は1件のキャッシュを再利用します。ドラッグは相対位置を保ち、グループへの移動メニューは選択を詰めて配置します。

移動先はグループ内、開いたフォルダー内、重なりによる結合、独立配置を区別します。単独の通常タイルに重ねると TileGrouping.Plan がコピー上で通常のグループにまとめます。上や同じ高さの既存項目を先に確保し、名前の領域が衝突する場合は新しいグループだけを必要な分下へずらします。空きがあれば対象タイルの位置を保持します。グループ内の重なりはフォルダー作成、既存フォルダーは中への追加です。つかんだ位置を考慮した重なりと待機 / 確定表示を使い、タイマーで静止中も判定します。複数選択は単独タイルとのグループ作成と既存フォルダーへの追加に対応し、入れ子は拒否します。1つ残ったフォルダーは維持し、空になったときに削除します。

単独タイルのグループ化は、小さい方のタイル面積の40%が重なった状態から300ミリ秒で確定します。追跡中は30%まで許容して小さな揺れで待機をやり直さず、範囲外に出たら解除します。フォルダーは65%・1000ミリ秒です。これらは ReStart の調整値で、Windows の内部定数を計測したものではありません。

表示中かつ非アクティブ時に閉じる設定が有効な間は、プロセス外コールバックの EVENT_SYSTEM_FOREGROUND を監視します。タスクバーのプレビューで一度非アクティブになった後の切り替えも検知し、現在の前面ウィンドウ、所有関係、表示世代、イベント時刻を再確認します。所有するダイアログと一時的なタスクバー・メニューは除外し、サムネイルのクリックも終了判定に含めます。非表示、設定無効、終了時に監視を解除します。

1枚のプレビューと確定は同じ移動先解決を使います。小さい単独タイルを大きいタイルが覆い、中心が相手の領域外に出る場合も重なりで解決します。OLEドラッグ中のタイマーはイベントの最新座標を表示領域基準で保持し、スクロール後に再変換します。つかんだ時点の座標が返る場合があるWPFマウスのポーリングは使いません。領域外への移動、終了、取消でタイマーを止めます。

## シェル・入力・保存

AppCatalog は STA で AppsFolder とユーザー / 共通の .lnk / .url を列挙し、OS表示名・階層を保持します。AUMID、一意の起動先＋引数、曖昧でない名前で照合し、判別できない項目は誤統合しません。アイコンは Freeze して共有し、ネイティブ資源を解放します。

入力設定は列挙前に反映し、読み込み完了時に待機中の検索語を再検索します。個別メニューは有効な canonical verb だけを表示し、実行時に ID を再照会します。プレビューでは実行しません。

ユーザー・セッション単位の Mutex とイベントで多重起動を防ぎます。フックは専用スレッドで短く処理し、UI は Dispatcher に渡します。Explorer の書き換えや DLL 注入は行いません。終了時に登録を解除します。

schema 4 は保存元アプリ版と直近の移行記録を持ちます。旧 schema / アプリ更新の原本を保全後、一時ファイルから置き換えます。将来の形式・保存元は上書き禁止です。[移行](migration.md)を参照してください。

更新 API は固定の公開宛先を認証なし・上限付きで読み、資格情報は保存しません。自動インストールは行いません。[更新](updates.md)を参照してください。

## 描画・JS

WorkingArea と PerMonitorV2 を使い、タイルは DIP と論理セルで配置します。背景のぼかしは Acrylic の近似です。テーマは共通リソース、文言は型付きキーと8言語 JSON、公開 API は XML コメントをビルドで検証します。

JS は4ワーカー共有・更新別エンジンで、制限付き JSON を現ユーザー専用の非同期パイプで渡します。親側の期限と Job Object が寿命・メモリを制限します。ライブラリはソースを実行せずメタデータを自動検出します。OS 権限を落としたサンドボックスではありません。[JS ガイド](javascript-tiles.md)に上限を記載しています。

## 現行契約

スキーマ4へ旧1～3から原本を保存して移行します。8言語、15種類のJSタイル、4ワーカー共有、PC時刻・集計メトリクス・選択フォルダ写真・タイル内クリック・明示したWeb API/フィード/ローカルファイル入力に対応します。新規カスタムタイルは既存グループに割り込まず空き場所へ独立配置します。データ接続はネイティブ画面で設定し、現ユーザーのDPAPIで暗号化して出力から除外します。更新確認は公開APIを認証なしで利用し、データ接続認証とは分離します。最新の詳細はリンク先の英語版と[JSガイド](javascript-tiles.md)を参照してください。
