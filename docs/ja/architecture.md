# アーキテクチャ

[English](../architecture.md)

ReStart.Core はモデル・配置・検索・翻訳・保存・更新 API の検証を扱います。ReStart.App は WPF、シェル、入力フック、トレイ、設定とワーカー管理、ReStart.TileHost は Jint による JS の実行を担当します。

## 配置

TileLayout は明示したセルを先に予約し、未配置 / 衝突項目を配置します。4サイズは1×1 / 2×2 / 4×2 / 4×4です。GroupLayout は列と半セル単位の縦アンカーを保持し、プレビューはモデルを変更せず、確定時と同じ衝突計算を使います。グループ移動では内部タイルの ID・サイズ・セルを変えません。

schema 4 の IsStandalone は単独タイルを表します。見出し・グループメニューを持たず、実際のタイル幅と高さで判定します。タイルの Column が列内のオフセット、グループの Row が画面上の縦位置です。これはユーザー要望に合わせた ReStart の拡張で、本家の内部モデルと一致するという主張ではありません。グループの幅は内容から求め、設定の6 / 8セルは内部の折り返し上限です。X は横方向の論理セルで、半セル単位に移動し、画面外の内容は横スクロールします。

GroupBoardPanel は同じ矩形で計測・描画し、LayoutEditor が所有権を一度だけ移します。フォルダー展開は一時的な高さで、保存したルート座標を変更しません。単独フォルダーの展開も親の横位置を保持します。

## シェル・入力・保存

AppCatalog は STA で AppsFolder とユーザー / 共通の .lnk / .url を列挙し、OS表示名・階層を保持します。AUMID、一意の起動先＋引数、曖昧でない名前で照合し、判別できない項目は誤統合しません。アイコンは Freeze して共有し、ネイティブ資源を解放します。

入力設定は列挙前に反映し、読み込み完了時に待機中の検索語を再検索します。個別メニューは有効な canonical verb だけを表示し、実行時に ID を再照会します。プレビューでは実行しません。

ユーザー・セッション単位の Mutex とイベントで多重起動を防ぎます。フックは専用スレッドで短く処理し、UI は Dispatcher に渡します。Explorer の書き換えや DLL 注入は行いません。終了時に登録を解除します。

schema 4 は保存元アプリ版と直近の移行記録を持ちます。旧 schema / アプリ更新の原本を保全後、一時ファイルから置き換えます。将来の形式・保存元は上書き禁止です。[移行](migration.md)を参照してください。

更新 API は固定の公開宛先を認証なし・上限付きで読み、資格情報は保存しません。自動インストールは行いません。[更新](updates.md)を参照してください。

## 描画・JS

WorkingArea と PerMonitorV2 を使い、タイルは DIP と論理セルで配置します。背景のぼかしは Acrylic の近似です。テーマは共通リソース、文言は型付きキーと8言語 JSON、公開 API は XML コメントをビルドで検証します。

JS は4ワーカー共有・更新別エンジンで、制限付き JSON を現ユーザー専用の非同期パイプで渡します。親側の期限と Job Object が寿命・メモリを制限します。ライブラリはソースを実行せずメタデータを自動検出します。OS 権限を落としたサンドボックスではありません。[JS ガイド](javascript-tiles.md)に上限を記載しています。

## v0.6 の現行契約

スキーマ4へ旧1～3から原本を保存して移行します。8言語、12種類のJSタイル、4ワーカー共有、PC時刻・集計メトリクス・選択フォルダ写真・タイル内クリックに対応します。新規カスタムタイルは既存グループに割り込まず空き場所へ独立配置します。下端グループの移動中も盤面範囲を保ち、同一プレビューの再レイアウトを省きます。更新確認は公開APIを認証なしで利用し、資格情報UIはありません。最新の詳細はリンク先の英語版と[JSガイド](javascript-tiles.md)を参照してください。
