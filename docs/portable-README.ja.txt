ReStart v@VERSION@
「配置を編集」/ Ctrl+E で起動せずにタイルを複数選択し、まとめてドラッグできます。
Ctrl+Z で配置を取り消し、Ctrl+Y / Ctrl+Shift+Z でやり直します。履歴は起動中のみです。
フルスクリーンのスタートを、もう一度。 English: README.txt

ReStart.exe を起動してください。TileHost・Examples・third-party・ライセンスを保持します。
.NET 同梱で通常利用に管理者権限は不要です。Windows キー、Start ボタン、
Ctrl+Alt+Space、トレイから開閉。歯車で設定、トレイで終了。起動登録は任意です。

タイル・グループをドラッグし、空白へ落とすと独立ピンになります。
グループ名はダブルクリック編集。単独タイルは半分ほど重ねて約0.3秒でグループ作成。
グループ内は約1秒でフォルダ作成、既存フォルダは追加。1つ残ってもフォルダを維持します。文字入力で検索。
Explorer の「ReStart にピン留め」は Windows 11 の「その他のオプションを確認」にあります。
設定の JS ギャラリーに12種類を同梱。通常クリックはタイル内操作、右クリックで
JS・設定の編集や写真フォルダ指定。PC 時刻と集計メトリクス API を利用できます。
スクリプトに任意ファイル・ネットワークへのアクセスは提供しません。

8言語、ダーク・ライト・システム・ハイコントラストに対応。
情報でバージョンとライセンス、レイアウトで移行記録を確認できます。
更新は API キー不要の公開 GitHub 確認。インストールは終了後 ZIP 全体を展開。
設定: %LOCALAPPDATA%\ReStart\layout.json。旧1～3から4へ元ファイルを保存して移行。
レイアウト出力に JS ソースと写真フォルダ指定は含まれません。tiles も保管してください。

削除時は起動登録と Explorer 連携を無効にし、終了後に展開先を削除。
ローカル設定は別に残ります。配布物は未署名、MIT ライセンスです。
Microsoft から独立したプロジェクトです。ソース・ビルド・実装情報:
https://github.com/LastResolution/ReStart

タイルライブラリ: %LOCALAPPDATA%\ReStart\TileLibrary にパッケージフォルダを置くと設定が自動検出します。
