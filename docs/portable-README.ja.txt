ReStart v@VERSION@
全画面のスタートを、もう一度。
English: README.txt

ReStart.exe を起動します。.NET の別途導入や管理者権限は不要です。
TileHost・Examples・third-party も同じ場所に保持してください。
Windows キー単押し / Ctrl+Alt+Space / 通知領域アイコンで開きます。
設定は左の歯車、終了は通知領域の ReStart メニューです。
サインイン時の自動起動は任意で、初期状態は無効です。

グループ内・グループ間でタイルを移動できます。空き領域へ出すと、
見出しやグループ幅を持たない単独タイルになります。
グループ移動は見出しをドラッグし、改名はダブルクリックで直接編集します。
別タイルの中央で約1秒保持してから落とすとフォルダーになります。
すべてのアプリから右クリックでピン留め。ホームで入力すると検索します。

設定 → 情報: バージョン・ビルド・ライセンス全文。
設定 → レイアウトとデータ: 移行記録と復元用バックアップ。
設定 → 更新: 手動 / 起動時チェック。非公開版の確認には対象リポジトリの
Contents:read 権限の GitHub トークンを Windows 資格情報へ保存します。
自動インストールは行いません。終了して ZIP 全体を展開し直してください。

保存先: %LOCALAPPDATA%\ReStart\layout.json
schema 1/2 は原本バックアップを残して schema 3 へ移行します。
旧版へ戻す場合は終了し、対応する旧形式のバックアップを復元します。
JS 本体はレイアウトのエクスポートに含まれないため、別途保全してください。

削除: 自動起動をオフ → 必要なら更新用トークンを削除 → 終了 →
展開したフォルダーを削除。設定データは別に残ります。

未署名の開発用プレリリースです。旧 UWP 通知・Windows Search 全体・
Jump Lists は非対応です。スタートボタン捕捉は試験的機能です。
物理 Windows キー / タスクバー操作、Windows 10 22H2 との実機比較、
ARM64 実機・異なる DPI の組み合わせは未検証です。
