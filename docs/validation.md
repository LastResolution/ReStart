## 自動テストが守る条件

- 4種類の論理サイズ、混在タイル200個の非重複と境界内配置。
- タイル移動・同じグループ内の挿入・フォルダー作成と最後の子の取り出し。
- 自分の親フォルダーに戻す操作でデータが消えないこと。
- 全角英数、ひらがな・カタカナの検索、複数語、検索順位と件数。
- JSON の保存・直前バックアップ・破損ファイル保全・将来バージョンの上書き禁止。
- 左右の Windows キー単押し、組み合わせ、修飾キー、連続操作の状態遷移。

## まだ確認していないこと

- Windows 10 22H2 と同時に操作して比較する検証。
- Windows キーと Win+E / D / L / Tab の実入力、サインイン時の起動、電源操作。
- タスクバーのスタートボタン捕捉、Win32 / Store アプリの全種類の実起動。
- Windows 10 / ARM64 の実機、複数モニターと各 DPI、タッチ、Narrator。

Windows のショートカットを制限する UI 自動化ツールでは、それらの入力を送っていません。コアの状態遷移テストを、OS での実動作の確認と混同しません。

配布の保証範囲は [再現仕様](fidelity.md) と合わせて確認してください。
