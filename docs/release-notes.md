Windows 10 の全画面スタートを参考にした、ReStart 最初の開発版です。

- ネイティブ全画面ランチャー、タイル、グループ、フォルダー、アプリ一覧と検索。
- 4種類のタイルサイズ、ドラッグ、名前変更、時計・日付タイル。
- 実アプリの列挙・アイコン、Win32 / Store アプリの起動。
- ローカル保存、バックアップ、テーマ設定、任意の自動起動。
- x64 / ARM64 の自己完結型 ZIP と SHA-256。

完全互換版ではありません。旧 UWP ライブ通知、Windows Search 全体、XAML タスクバーのスタートボタン置き換えなどには制限があります。Windows キーの組み合わせ、Windows 10、ARM64、複数画面は追加の実機確認が必要です。

ZIP を展開して ReStart.exe を起動してください。管理者権限と .NET の別途インストールは不要です。未署名の開発版です。

操作と制限は README、docs/fidelity.md、docs/validation.md を参照してください。
