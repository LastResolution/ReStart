# ReStart v0.2.0

Windows 10 の全画面スタートを参考にした、非公開の開発版です。v0.1.1 から、ドラッグの実動作、左寄せの配置、テーマに沿った設定画面、多言語対応、JavaScript ライブタイルを改善しました。

## 配置と操作

- ボタンにドラッグ開始が届かず、タイルが移動できない問題を修正。空きセルや別グループへの移動位置を保存します。移動先の枠と、画面端でのスクロールも追加しました。
- グループ数が少ないと右に寄っていた初期配置を左寄せに変更。検索の「最も一致するアプリ」と結果も同じ余白に揃えました。
- 全アプリ一覧の列の高さを揃え、文字見出しだけが列の末尾に残りにくくしました。
- 開いた直後の入力先をネイティブの検索欄へ変更。単語先頭一致を優先し、E で Microsoft Edge が候補上限に埋もれる問題を修正しました。
- タスクバーのクリックで閉じる処理を追加。クリック自体は Windows に渡します。ダイアログやドラッグの最中には閉じません。

## 外観と言語

- 設定をカテゴリ別ナビゲーションに整理し、保存・閉じるボタンを固定。操作ボタンの文字は中央揃えにしました。
- チェックボックス、選択欄、スライダー、スクロールバー、カレンダーをダーク／ライト／システムテーマに合わせて描画します。
- 日本語／English／システム言語を選択可能。保存後に UI、日付、メニュー、アクセシビリティ名を切り替えます。保存済みのアプリ名・グループ名・タイル名は変更しません。
- 日本語原文を翻訳キーに使う方式を廃止し、型付き TextKey と言語別リソースに分離しました。公開 API の XML ドキュメントコメントをビルドで検証します。

## JavaScript ライブタイル

設定 → JavaScript タイルからサンプルを作成し、メモ帳で tile.js を編集できます。manifest.json と tile.js のインポートにも対応します。時計とカウントダウンを同梱しました。

時刻・言語・設定・前回の状態を受け取り、文字、補足、バッジ、色、進捗を返す API です。保存後の次の更新で反映し、エラー時は最後に成功した表示を保持します。実行は専用プロセスに分離し、時間・メモリ・通信サイズを制限します。ネットワーク、ファイル、Node.js、DOM、CLR は公開しません。

作り方と制限は [JavaScript タイル開発ガイド](https://github.com/LastResolution/ReStart/blob/v0.2.0/docs/javascript-tiles.md) を参照してください。旧 UWP の通知配信を再現するものではありません。

## 常駐と自動起動

- 通常起動はユーザー・ログオンセッションごとに1つ。別の場所の実行ファイルを起動しても既存画面へ通知します。検証用プレビューはタイトルを明示した別モードです。
- 設定 → 起動と操作で、実際の自動起動登録を読み取って登録／解除します。設定保存の失敗時には登録を復元します。
- サインイン時は画面を開かず通知領域に常駐。バックグラウンドからの二度目起動でも画面を開きません。プレビューから自動起動の登録は変更できません。

## ダウンロードと更新

1. x64 PC は ReStart-win-x64.zip、ARM PC は ReStart-win-arm64.zip を選びます。SHA-256 を同梱しています。
2. 起動中の旧版を通知領域から終了し、ZIP 全体を展開してください。TileHost、Examples、third-party も本体と一緒に置きます。
3. ReStart.exe を起動します。.NET ランタイムの別途インストールと管理者権限は不要です。
4. 自動起動を使っていて展開場所を変えた場合は、新版の設定で自動起動をオンにして保存し、登録先を更新してください。

保存済みレイアウトは %LOCALAPPDATA%\ReStart に残ります。配布物は未署名のプレリリースです。リポジトリとリリースは非公開のままです。

## 検証と既知の制限

- Windows x64 の Release ビルド、73件のテスト、検索画面と JS タイルの描画を確認。2か所からの10回の重複起動、ワーカー停止後の復帰、自動起動登録の復元も検証しています。
- E 検索の順位と描画は確認済みです。物理 Windows キーからの入力、実際のタスクバークリック、再サインインの通し確認は未実施です。
- Windows 10 との完全一致、ARM64 実機、複数画面・異なる DPI、タッチ、Narrator は追加検証が必要です。
- Windows 11 の XAML タスクバーにおける Start ボタン捕捉は試験的です。旧 UWP 通知、Cortana、ファイルを含む Windows Search 全体、最近使った項目は含みません。
