# ReStart v0.2.2

全アプリ一覧の右側に大きな空白が残る問題と、開き直しても一覧画面が残る問題を修正した、非公開のプレリリースです。

## 修正内容

- 全アプリ一覧の最大4列・固定幅を廃止。表示領域に合わせて列数と列幅を調整し、右側まで使用します。文字見出しもアプリアイコンに合わせて左揃えにしました。
- 全アプリ一覧や検索画面で閉じた後、開き直すとピン留めタイル画面の先頭へ戻ります。検索語、フォルダー、文字ジャンプ、展開メニューも閉じます。
- アプリ一覧の文字見出しが列の末尾に取り残されない配置は維持しています。保存したタイル配置・グループ名・テーマは保持します。
- プレビューの再表示ではウィンドウサイズを維持し、通常起動と同じ画面状態の初期化を検証できるようにしました。

## 検証

- Releaseビルド: 警告0・エラー0、73件のテスト合格。
- 架空アプリ288個を使い、800 / 1280 / 1920 / 2560 DIP幅の実際のWPF配置を検証。右端の使用、はみ出し、文字見出しの分断を確認しました。
- 一覧・検索からのHide / Presentを計8回実行し、タイル画面の先頭へ戻ることと、検索・オーバーレイの解除を確認しました。この回帰チェックをCIに追加しています。
- 物理Windowsキーと実際のタスクバークリック、異なるDPI、ARM64実機の通し確認は未実施です。Windows 10との完全一致を保証するものではありません。

## 更新方法

1. x64 PCはReStart-win-x64.zip、ARM PCはReStart-win-arm64.zipをダウンロードします。SHA-256も添付しています。
2. 起動中の旧版を通知領域から終了してから、ZIP全体を展開してください。TileHost、Examples、third-partyも本体と一緒に置きます。
3. ReStart.exeを起動します。.NETランタイムの別途インストールは不要です。
4. 自動起動を使っていて展開場所を変えた場合は、新版の設定で自動起動をオンにして保存し、登録先を更新してください。

保存済みレイアウトは%LOCALAPPDATA%\ReStartに残ります。配布物は未署名です。リポジトリとリリースは非公開のままです。
